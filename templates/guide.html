{{ ui.icon('info-circle-fill', 'bi text-primary', 16) }} 一、系统是干什么的？

这个系统是用来按月收集各部门结算资料的。每个月底到次月初，各部门需要提交结算相关的数据和文件，合同管理部汇总后进行对上（总包）和对下（分包）结算。

{{ ui.icon('arrow-up-circle', 'bi', 16) }} 对上结算（总包）

向联营体/总包方报送资料，证明完成工作量、扣款依据等，获取工程款。

{{ ui.icon('arrow-down-circle', 'bi', 16) }} 对下结算（分包）

向分包商扣款/核量，包括质量扣款、安全扣款、水电住宿伙食扣款等。

{{ ui.icon('lightbulb', 'bi', 16) }} 一句话理解： 每月各部把自己的数据交上来 → 合同管理部汇总 → 对上要钱、对下扣钱。

{{ ui.icon('diagram-3-fill', 'bi text-primary', 16) }} 二、每月结算怎么走流程？

1
每月1日：系统自动生成当月任务

打开系统仪表盘，选择当月，所有部门的提交任务自动出现。

2
每月1日~28日：各部门分头提交

各部门在「提交数据」页面找到自己的任务，逐条提交文件或标记「无」。截止日期见各任务配置。

3
每月28日~30日：合同管理部催收

仪表盘上看进度条，红色=逾期，黄色=部分提交，绿色=已完成。催没交的部门。

4
月底前：汇总视图核对

在「汇总视图」页面查看所有条目的提交状态，下载已提交的文件，准备结算书。

5
次月：历史记录可追溯

「历史记录」页面查看所有提交记录，随时翻查往月数据。

{{ ui.icon('window-stack', 'bi text-primary', 16) }} 三、各页面功能说明

页面 谁用 干什么
仪表盘 所有人 总览当月进度，看哪些部门交了、哪些没交。红色=逾期、黄色=部分提交、绿色=已完成。
提交数据 各部门 各部门在这里找到自己的任务，点进去逐条提交文件或标记「无」。最常用的页面。
汇总视图 合同管理部 所有条目提交情况一览表，可以按对上/对下筛选，下载已提交文件和模板。
模板文件 所有人 管理扣款单模板文件。各部门下载空白模板填写，管理员可以上传新模板。
配置管理 管理员 配置各部门的提交任务、截止日期、备注。灰色标注「已停用」的部门不参与收集。
历史记录 所有人 查看所有历史提交记录，可翻页浏览，追溯往月数据。

{{ ui.icon('cloud-arrow-up-fill', 'bi text-primary', 16) }} 四、怎么提交数据？（最常用）

{{ ui.icon('exclamation-triangle', 'bi', 16) }} 这是最核心的操作，看完这段就会用了。
步骤1：进入提交页面

点击顶部导航栏「提交数据」，选择当前月份。你会看到所有部门的任务列表，找到自己部门。

步骤2：点进任务详情

点击任务行的「查看详情」按钮，进入条目列表页。每个任务被拆成了独立条目，比如「质量验收记录」「工程量确认」等，每条可以单独提交。

步骤3：逐条提交

每条条目有三种操作方式：

{{ ui.icon('file-earmark-arrow-up', 'bi', 16) }} 上传文件

选择文件上传。支持 Excel、Word、PDF、图片、压缩包等格式。填好提交人姓名后提交。

{{ ui.icon('dash-circle', 'bi', 16) }} 标记为「无」

本月没有对应内容就点「标记无」。这算作已处理，不是漏交。

{{ ui.icon('arrow-counterclockwise', 'bi', 16) }} 撤销/重交

已提交的条目可以撤销重交，或直接上传新文件覆盖旧文件。

步骤4：检查进度

提交后回到列表页，进度条会更新。全部条目都提交/标记后，状态变绿色「已完成」。

{{ ui.icon('lightbulb', 'bi', 16) }} 批量标记： 如果整个任务本月全部没有内容，可以用「全部标记为无」按钮一键处理。

{{ ui.icon('file-earmark-spreadsheet', 'bi text-primary', 16) }} 五、水电住宿费扣款表填写说明

水电、住宿、伙食等扣款单由综合办公室负责填写提交。所有扣款表结构相同，按以下规则填写：

扣款表通用结构
列名 含义 怎么填
序号 行号 自动编号，不用管
姓名 / 单位名称 被扣款人 填分包商人员姓名或单位名
开始时间 / 结束时间 在场起止日期 填本月内的在场日期范围
人数 / 间数 住宿费填房间数，其他填人数 住宿费：填实际使用的房间数；餐费：填份数；水电：填人数
在场天数 实际天数 结束日期 - 开始日期 + 1
天/比索（单价） 扣款单价 按下方收费规格速查表填写（可直接在页面修改）
累计到上期扣款合价 历史累计已扣金额 从上月扣款表抄过来
本期扣款合价 本月应扣金额 住宿费 = 间数 x 2000；餐费 = 份数 x 30
备注 补充说明 如有特殊情况注明
{{ ui.icon('calculator', 'bi', 16) }} 计算公式（按费用类型区分）：
  • 住宿费 = 房间数 x 2000 比索/间（固定按间收费，与住几人无关）
  • 餐费（伙食费） = 份数 x 30 比索/份
  • 水费 / 电费 = 待与总包确认收费标准后补充
{{ ui.icon('info-circle', 'bi', 16) }} 举例： 3间宿舍，每间住4人 → 住宿费扣款 = 3 x 2000 = 6,000 比索
餐费举例： 50份餐 x 30比索 = 1,500 比索
涉及的扣款表（共6类，已全部配模板）
扣款类型 对上/对下 负责部门 模板文件
